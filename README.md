# Netcode Learning
Files on starting 3D multiplayer in Unity through Netcode for GameObjects. This is not an expansive test, nor is it probably the most comprehensible. This is a showcase that I have an understanding of how to handle code on both the client and on the user, and how to maintain fluid, yet synced, positions between multiplayer players, without frequent snapping and rubber banding, even on higher pings.

I created a basic tutorial that walks through an overview of this step by step.
